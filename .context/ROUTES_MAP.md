# 🗺️ Palabrario — Mapa Canónico de 22 Rutas, Casos de Uso, Métodos IPC y DTOs (`.context/ROUTES_MAP.md`)

> **Propósito de este documento (SSOT de Enrutamiento y Contratos UI $\leftrightarrow$ Backend):**  
> Este documento desglosa la matriz de trazabilidad exacta de las **22 Rutas Canónicas de Vue Router (`createWebHashHistory()`)** (+ ruta administrativa `#23` y menú global `TopBar`) hacia:
> 1. Los **16 Casos de Uso (`CU01–CU16`)** y **13 Reglas de Negocio (`RN01–RN13`)** de [`.context/DOMAIN.md`](./DOMAIN.md).
> 2. Los **6 Diagramas de Secuencia Interactivos** en [`.context/UI_FLOWS.md`](./UI_FLOWS.md).
> 3. Las firmas exactas del contrato polimórfico **`IPalabrarioAPI = typeof WailsAppBridge`** expuesto por [`local-app/app.go`](../local-app/app.go) e implementado en espejo por `CapacitorMobileAdapter`.
> 4. Los endpoints reales de [`core-service/internal/api/router.go`](../core-service/internal/api/router.go) (`:8000`), [`realtime-service`](../realtime-service/main.go) (`:8001`) e [`image-service`](../image-service/main.go) (`:8002`).
> 5. Los structs Go reales de [`pkg/models/`](../pkg/models) transpilados a TypeScript en `wailsjs/go/models.ts`.

## 1. Convenciones de Layouts y Guardias de Navegación (`vue-router`)

| Layout (`meta.layout`) | Descripción y Comportamiento Visual | Vistas que lo Utilizan |
| :--- | :--- | :--- |
| **`default`** | Estructura principal con barra superior (`TopBar.vue` + `DropdownMenu` de usuario + `CredentialsRolePopover.vue`), buscador omnibox (`Ctrl + K`), racha de usuario y barra inferior móvil (`BottomNav.vue`) sobre fondo `bg-paper`. | Portada, Diccionario, Explorador de Barajas/Colecciones, Perfil Social, Studio, Panel Editorial y Panel de Gobernanza. |
| **`auth`** | Lienzo centrado minimalista sobre `bg-paper` con tarjeta táctil editorial (`card-editorial`), sin barras de navegación distraídas. | Inicio de sesión (`/#/auth/sign-in`) y Registro (`/#/auth/sign-up`). |
| **`immersive`** | Pantalla completa de enfoque total sin `TopBar` ni `BottomNav`, con barra de progreso superior y atajos de teclado (`1–4`, `Space`, `Esc`). | Sesión de Repaso SM-2 (`/#/studio/study`) y Partida de Arena en Vivo (`/#/game/:roomCode`). |

| Guardia (`meta.auth`) | Regla de Acceso en el Router |
| :--- | :--- |
| **`public` / `OptionalAuth`** | Accesible para invitados y usuarios autenticados. Si hay sesión activa, el backend enriquece la respuesta (ej. `is_owner == true` en perfil). |
| **`guestOnly`** | Solo accesible sin sesión activa. Si el usuario ya está autenticado, redirige automáticamente a `/#/`. |
| **`requireAuth`** | Requiere sesión activa (`LEARNER`, `EDITOR` o `ADMIN`). Si no hay sesión, redirige a `/#/auth/sign-in`. |
| **`requireRole: ['EDITOR', 'ADMIN']`** | Exclusivo para cuerpo editorial y administradores. Si un `LEARNER` intenta entrar, abre el Popover *"Credenciales y Rol en la Imprenta"* en `TopBar` (`CU02` / `CU04`). |
| **`requireRole: ['ADMIN']`** | Exclusivo para administradores institucionales (`CU03, CU04, CU09, RN08`). |
